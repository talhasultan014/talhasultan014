## About Me

I'm **Muhammad Talha Sultan**, a **BS Cybersecurity student at COMSATS University Islamabad** with an interest in both defensive and offensive security.

My **primary focus is Blue Team and Security Operations Center (SOC) fundamentals**. I'm currently developing my understanding of security monitoring, log analysis, threat detection, alert investigation, and incident response. I also explore **web application security and penetration testing** to understand attacker techniques and their defensive implications.

Alongside cybersecurity, I build software projects and explore **security automation**. My longer-term direction is **cloud security and detection engineering**.

- **Current focus:** SOC fundamentals, Blue Team practices, and threat detection
- **Complementary interests:** Web security, offensive techniques, and security automation
- **Future direction:** Cloud security and detection engineering
- **Learning approach:** Hands-on tools, practical projects, and CTF participation
